# 關卡前的漫畫

每一關開始前播的一段漫畫，畫風是 1960 年代美式漫畫的印刷風格。每個檔案都是獨立的網頁，沒有另外的圖片檔，畫面全部用程式（SVG）畫出來。

| 檔案 | 什麼時候播 | 內容 | 播完進哪一關 |
|---|---|---|---|
| `ch1.html` | 第一關之前 | 前情提要，兩頁九格，約 31 秒 | `levels/ch1.json` |
| `ch2.html` | 第二關之前 | 從山路到總部大樓，一頁四格，約 14 秒 | `levels/ch2.json` |
| `ch3.html` | 第三關之前 | 進入總部找燃料，一頁四格，約 15 秒 | `levels/ch3.json` |

## 怎麼看

先在 repo 根目錄啟動伺服器：

```
node tools/serve.mjs
```

再開 `http://localhost:8080/web/comics/ch2.html`。

- 按任意鍵或點一下畫面可以跳過。
- 播完或跳過之後，會自動跳到 `web/index.html?level=chN`。
- 那一關的關卡檔還不存在時，會停在最後一頁並顯示提示，不會跳到壞掉的頁面。
- 網址後面加 `?stay`，播完會停在最後一頁，不進關卡。檢查漫畫時用這個。
- 直接用檔案打開（不透過伺服器）是預覽模式，也不會自動進關卡。

## 怎麼接到遊戲

想讓玩家先看漫畫再進關卡，把原本連到 `index.html?level=chN` 的地方改成連到 `comics/chN.html` 就可以，遊戲的程式不用改。

## 想修改的話

每個檔案最下面的 `<script>` 裡：

- `LEVEL`：播完要進哪一關。
- `PANELS`：每一格從哪裡飛進來、全螢幕停多久、縮小後對準畫面的哪裡。
- 在瀏覽器的 console 輸入 `__show(0)`，可以直接看第 1 格全螢幕的樣子。
