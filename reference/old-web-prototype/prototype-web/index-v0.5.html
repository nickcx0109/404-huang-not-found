操作方式

WASD
移動，Shift 衝刺，Space 跳躍
滑鼠
瞄準，左鍵攻擊（步槍、噴火槍、電鋸、武士刀可以按住）
E
使用櫃台、投抽獎幣
R
換彈
1–8
換武器，也可以用滾輪；手槍以外的武器都要在商店買
Q
拿出燃燒彈或手榴彈，左鍵丟出，T 切換種類，再按 Q 或數字鍵收回
F
打腎上腺素：8 秒內跑更快、攻擊更快、換彈更快
G
交易時間提早開始下一關
L
顯示或隱藏事件紀錄
Esc
暫停與設定（滑鼠靈敏度），在交易站裡按會離開櫃台

成就與累積紀錄

紀錄自動存在這台電腦的瀏覽器裡（localStorage），關掉網頁再打開還在。換瀏覽器、用無痕視窗或清除網站資料就會不見。
