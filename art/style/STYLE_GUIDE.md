# 風格規則

這一版要的是「看不清楚、光源很少、顏色髒」，不是上一版那種藍色月光、看得很清楚的夜晚。規則來自 [SCENE_PIPELINE.md](../../docs/art/SCENE_PIPELINE.md) 第 2 節，數值都放在 [palette.json](palette.json)，程式不寫死。

## 規則

| 項目 | 目標 |
|---|---|
| 霧 | 灰綠，約 `#2a3330`；`FogExp2` 密度 0.035～0.05，視距 20～30 m |
| 曝光 | 0.8～0.95，暗部壓到接近全黑 |
| 主要光源 | 玩家手電筒（SpotLight），加少數場景光 |
| 飽和度 | 0.75～0.85，只有重點色是飽和的 |
| 後製 | 暗角、顆粒，重的版本加一點色差 |

1. 玩家要找的東西（車、燃料桶、出口）永遠比背景亮。陰森不能變成看不到路。
2. 每個鏡頭最多 1～2 個重點色，而且只用在要引導玩家的地方。
3. 同時開著的動態燈不超過 4 盞（含手電筒），只有手電筒投影；其餘用自發光材質假裝。
4. 殭屍在霧裡要先看到輪廓或眼睛反光，再看到細節。

各章重點色：

| 章 | 基調 | 重點色 |
|---|---|---|
| 一、找車 | 灰綠霧、近黑的樹 | 車尾燈的紅 `#ff3b2f` |
| 二、堅守陣地 | 濕柏油的深藍灰 | 故障招牌的綠 `#76ff3a`（標誌自己設計） |
| 三、總部救人 | 停電的黑、紅色應急燈 | 燃料桶的橘黃 `#ffb020` |

## palette.json 怎麼讀

- 最上層每個鍵是一個區塊（`default`、`mood`、`ch2`，之後 `ch1`、`ch3`；`blockout` 是看配置圖用的，不是遊戲的樣子）。每個區塊都疊在 `default` 上面，只要寫不一樣的地方。關卡用 `"palette"` 欄位選區塊。
- 章節區塊用 `"extends": "mood/heavy"` 從選定的氣氛出發，再寫這一章要改的地方。
- 區塊可以有 `presets`，網址用 `?preset=<名稱>` 切換；`defaultPreset` 是沒給時用哪一組。
- **`fog.color` 是「畫面上看到的顏色」**。程式會把曝光、tone mapping、飽和度反推回去，所以色票寫 `#2a3330`，畫面上的霧就是 `#2a3330`（畫面中央；四角會被暗角壓暗）。其他顏色是物體或燈光的顏色，會跟著曝光變亮變暗。
- `accent` 是該章的重點色。`intensity` 大於 1 才會發光（bloom）並穿過霧；`light` 是它照在旁邊地面上的小燈，算一盞動態燈；`flicker` 讓它像故障的招牌一樣閃。
- `alarm` 是紅色警示燈。`light.count` 是幾個警示燈有真的燈，`sweep` 是光往左右各擺幾度（0 就是轉整圈）。
- 動態燈上限 4 盞（含手電筒）。`moon.intensity` 設 0 就不建立月光，把名額讓給場景燈。

## 三組候選（已選定 heavy）

**2026-11-15 選定 heavy**，已設為 `mood` 的 `defaultPreset`。subtle、medium 留著做比較。之後各章的氣氛以 heavy 為基準；表格裡提到 heavy 整章使用會累、難瞄準，做戰鬥章節（例如第二章）時要特別注意手電筒範圍和重點光，必要時在該章區塊局部調亮。

場景是 `web/levels/mood.json`：一段約 30 m 的灰盒山路，兩旁枯樹，路中間一台廢車，盡頭是亮著紅色尾燈的車。三個機位：`road`（起點往前看，尾燈在 26 m 外）、`wreck`（廢車旁）、`car`（離車 8 m）。

截圖在 [refs/candidates/](refs/candidates/)，檔名 `<預設>-<機位>.jpg`。

| | subtle | medium | heavy |
|---|---|---|---|
| 感覺 | 陰天的黃昏。樹林和路都看得出形狀，手電筒是輔助。不安，但不壓迫 | 入夜的濃霧。路靠手電筒，樹只剩剪影，遠處只有尾燈是清楚的 | 幾乎全黑。只看得到手電筒照到的那一塊和尾燈，畫面四周被暗角吃掉 |
| 適合 | 要看清楚殭屍從哪來、戰鬥為主的段落 | 預期的基準，探索和戰鬥都行 | 短的驚嚇段落；整章都這樣會累，也難瞄準 |
| 霧色（畫面上） | `#333d39` | `#2a3330` | `#222a27` |
| 霧密度／視距 | 0.035／約 34 m | 0.042／約 28 m | 0.05／約 24 m |
| 曝光 | 0.95 | 0.88 | 0.8 |
| 飽和度 | 0.85 | 0.8 | 0.75 |
| 暗角 | 0.45 | 0.6 | 0.7（更早開始） |
| 顆粒 | 0.035 | 0.05 | 0.07，加色差 0.0025 |
| 半球光／月光 | 1.3／0.5 | 0.8／0.28 | 0.62／0.18 |
| 手電筒 | 強度 2.6、28° | 強度 2.4、26° | 強度 2.2、23°、只照 28 m |

視距是「物體只剩四分之一對比」的距離（1.18 ÷ 密度）。三組共用同樣的灰盒顏色、重點色和 bloom。

自己走走看（手電筒按 F 開關）：

```
node tools/serve.mjs
```

- <http://localhost:8080/web/index.html?level=mood&preset=subtle>
- <http://localhost:8080/web/index.html?level=mood&preset=medium>
- <http://localhost:8080/web/index.html?level=mood&preset=heavy>

`mood` 的 `defaultPreset` 是 `heavy`，不帶 `preset` 時就用 heavy。

## 第二章（ch2）：和 heavy 差在哪

第二章是守點，要看得到殭屍從左街、右街、停車場三個方向來。heavy 原樣套上去，廣場上只看得到手電筒照到的那一塊，所以 `ch2` 從 heavy 出發，只改下面這些。曝光 0.8、飽和度 0.75、顆粒 0.07、色差、bloom 都沒動，`mood` 區塊也沒動。

| 項目 | heavy | ch2 | 為什麼 |
|---|---|---|---|
| 霧色（畫面上） | `#222a27` 灰綠 | `#28313b` 深藍灰 | 第二章的基調是濕柏油的深藍灰；稍微亮一點，沒被照到的殭屍才有剪影 |
| 霧密度／視距 | 0.05／約 24 m | 0.04／約 30 m | 防守點到三個入口是 12～20 m，要看得到入口 |
| 半球光 | 灰綠，0.62 | 藍灰（天 `#8090a4`），2.6 | 地面和掩體要看得出形狀，不能只靠手電筒 |
| 月光 | 0.18 | 關掉 | 名額讓給警示燈（動態燈上限 4 盞） |
| 手電筒 | 2.2、23°、照 28 m | 2.8、30°、照 40 m | 戰鬥要照得到入口，光圈寬一點才看得到旁邊 |
| 暗角 | 0.7 | 0.55 | 敵人從兩側來，畫面邊緣不能太黑 |
| 重點色 | 紅 `#ff3b2f`（尾燈） | 綠 `#76ff3a`（招牌），會閃，其中一個字是壞的 | 第二章的重點色；招牌是自己設計的字和標誌 |
| 紅色警示燈 | 無 | 三個入口各一盞真的燈（強度 8、照 30 m），朝外左右各擺 55° | 殭屍走進入口時正面會被照紅；燈朝外擺而不是轉整圈，入口大部分時間是亮的 |
| 地面 | 粗糙度 0.95 | 0.6 | 濕柏油：迎著警示燈看，地上有紅色反光 |

動態燈剛好 4 盞：手電筒（唯一投影的）＋三盞警示燈。招牌只有自發光，不另外打燈；保全亭屋頂的警示燈也只有發光的燈罩。**其他玩家的手電筒還沒算進來**，接多人時要把 `alarm.light.count` 降到 1 或 0。

截圖在 [refs/ch2-greybox/](refs/ch2-greybox/)：7 張氣氛（`gate_view`、`left_post`、`right_post`、`front_post`、`gate`、`street_in`、`overview`）、1 張俯視配置圖（`plan`，用 `blockout` 區塊）、4 張 `*-dummies`（路線上放了殭屍大小的方塊）。

## 重拍截圖

```
npm install
npx playwright install chromium
node tools/art/shots.mjs --level mood --presets subtle,medium,heavy --out art/style/refs/candidates
```

工具會自己開、關 server，1280×720，用軟體繪圖（SwiftShader），每台電腦拍出來一樣。加 `--gpu` 改用顯示卡。

## 和計畫不一樣的地方

- **截圖存 JPEG（品質 85）不是 PNG**。顆粒要留著才看得出真實氣氛，但有顆粒的 1280×720 PNG 約 1.1 MB，超過每張 300 KB 的上限；JPEG 約 100～140 KB。要 PNG 時加 `--format png`。
- bloom 用四分之一解析度（計畫寫半解析度），在內顯上比較省，看起來差不多。
