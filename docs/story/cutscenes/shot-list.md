# 鏡頭清單

每個過場拆成的鏡頭，以及每個鏡頭要用哪張圖。完整分鏡表欄位（秒數、運鏡、聲音、銜接）會在試做後逐鏡補上，已完成的見 [test-shots.md](test-shots.md)。

動畫額度每天都有，照順序慢慢做，不必刪鏡頭。

狀態說明：

- **沿用**：初稿可以直接當第一幀
- **改圖**：初稿可用，但要請 GPT 修改部分內容
- **重畫**：初稿方向對，但要整張重生
- **新畫**：沒有對應的初稿
