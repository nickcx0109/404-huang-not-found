## 一句話故事

老黃的晶片讓世界陷入殭屍災難，他打電話要三位情婦趕到 MVIDIA 總部頂樓，搭上伊龍馬的四人火箭一起逃離地球，而火箭只認老黃的指紋。

## 核心設定

| 設定 | 內容 | 在故事裡的作用 |
|---|---|---|
| 生醫未來晶片 | 老黃公司的產品，裝上的人會異變成殭屍 | 災難的起因 |
| 四人逃生火箭 | 伊龍馬替老黃準備，停在總部頂樓 | 最終目標，剛好坐得下四人 |
| 指紋啟動 | 火箭只能用老黃的指紋發射 | 三人一定要救老黃，不能自己走 |
| 總部封鎖 | 爆發後大樓自動封鎖，大門上鎖、老黃困在頂樓 | 第二章要破譯大門的原因 |
| 燃料不足 | 火箭沒有燃油，要從大樓內收集汽油桶 | 第三章的任務 |
| 貨梯 | 能把燃料送上頂樓，但載重不夠載人 | 交燃料的地點 |
| 樓梯堵塞 | 暴動的殭屍破壞並堵住通往頂樓的樓梯 | 要找權限卡搭電梯 |
| 火星基地 | 伊龍馬祕密發展的基地 | 結局的去處 |

故事上的風險：老黃死了就沒有指紋，火箭沒有燃料就飛不了，結果就是四人困死在地球。遊戲失敗時直接重來，不另做失敗過場。

## 五段過場

預計總長約 3 分鐘，拆分鏡時再細算。

### 過場 1：開場（約 67 秒）

目的：交代晶片怎麼造成災難、老黃怎麼聯絡三人、要去哪裡，帶玩家進入第一章。

1. **晶片發表**：老黃在盛大的發表會上發表生醫未來晶片，台下觀眾都裝了晶片。
2. **晶片異常**：大螢幕上的晶片圖樣故障，觀眾後頸的晶片過亮、失控。
3. **變成殭屍**：觀眾異變成殭屍，會場大亂，老黃逃走；整座城市淪陷。
4. **打電話給情婦們**：老黃在總部頂樓打電話，山上營地小木屋裡的手機亮起他的照片和愛心。左右分割畫面，左邊老黃、右邊三人，通話內容用賽博龐克風的英文字幕交代：他的裝甲車在營地深處。
5. **頂樓有火箭，快來**：同一個分割畫面，字幕接著打出：頂樓有火箭、四個位子、快來。
6. **緊張地抄起傢伙**：三人一開始沒這麼兇悍，緊張地抓起球棒、步槍、手槍，走進營地深處 → **接第一章**。

逐鏡內容見[分鏡腳本](script.md)。

### 過場 2：第一章 → 第二章（約 35 秒）

目的：交代拿到車、抵達總部、大門鎖住，帶出第二章的守點任務。

1. 霧中的路盡頭，一台吉普裝甲車停在那裡。
2. 三人上車，發動。
3. 吉普車衝過殭屍群，突出重圍。
4. 車子停在 MVIDIA 總部門口，大門緊閉、電子鎖亮著紅燈。
5. 一人開始破譯電子鎖，進度燈只亮起幾格。
6. 遠處的殭屍群追了上來。
7. 另外兩人轉身架起武器 → **接第二章**。

### 過場 3：第二章 → 第三章（約 30 秒）

目的：交代進入大樓後的三個新任務：收集燃料、送到貨梯、找權限卡。

1. 電子鎖的燈全部亮起，大門打開。
2. 三人退進大樓，大門在殭屍面前關上。
3. 電話響起，老黃來電：火箭沒有燃油。
4. 大廳角落散落的汽油桶，以及一座貨梯（旁白：把燃料送進貨梯，貨梯載不了人）。
5. 通往頂樓的樓梯被殭屍破壞、堵死。
6. 一扇辦公室的門，門內桌上隱約可見一張權限卡（旁白：要拿權限卡才能搭電梯上頂樓）→ **接第三章**。

### 過場 4：頂樓 Boss 登場（約 25 秒）

目的：四人會合的短暫喜悅，被巨型殭屍打斷，帶出 Boss 戰。

1. 電梯門打開，頂樓上停著火箭，老黃背對鏡頭張開雙手。
2. 三人跑向老黃，四人會合。
3. 老黃走向指紋掃描器。
4. 頂樓邊緣，一隻巨大的手攀了上來。
5. 巨型殭屍爬上頂樓，一把抓起老黃。
6. 巨口張開，老黃的剪影被舉到嘴前。
7. 切到三人驚恐的臉，配吞嚥音效（吞的畫面不正面拍）。
8. 三人舉起武器 → **接 Boss 戰**。

### 過場 5：結局（約 40 秒）

目的：救回老黃、啟動火箭、抵達火星。

1. 巨型殭屍倒下。
2. 老黃從牠的肚子裡滑出來，全身黏液，趴在地上的背影，抬手比讚。
3. 三人把老黃拖到指紋掃描器前。
4. 沾滿黏液的手掌按上掃描器，燈號一格一格亮起。
5. 火箭點火升空，底下是被殭屍佔據的城市。
6. 火星基地的遠景，四人的背影站在紅色地平線前。
7. 旁白收尾：在新的星球重新開始，傳宗接代、發展新文明。
