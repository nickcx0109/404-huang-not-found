# 分鏡腳本

每一格畫面的內容與拍法。沒有角色對話，只在每段結尾加章節標題字幕。最後要用漫畫分格排版，還是滿版影片一幕一幕播，之後再決定，這份腳本兩種都適用。鏡頭編號對應 [shot-list.md](shot-list.md)。

場景細節對照遊戲目前的畫面：第一章是灰綠霧中的枯樹山路、終點是亮著紅色尾燈的車；第二章是濕柏油的深藍灰廣場、鋼製大門、故障的綠色招牌、紅色警示燈；第三章是停電的辦公室、紅色應急燈、橘黃色燃料桶。過場和遊戲要接得上，玩家看完過場一進遊戲就認得出地方。

**景別**：大遠景（看環境）→ 遠景 → 全景（人的全身）→ 中景（腰以上）→ 近景（胸以上）→ 特寫（臉或物件）→ 大特寫（眼睛、手）

**運鏡**：固定、推（靠近）、拉（遠離）、搖（鏡頭原地轉）、移（鏡頭平移）、跟（跟著主體走）

**每鏡的欄位**：標題列是「鏡號｜景別｜角度｜運鏡｜秒數 — 目的」，下面是畫面（構圖與人物）、光線、動作（給動畫用）、聲音、接下一鏡，必要時加注意。

## 過場 1：開場（17 鏡，約 67 秒）

**故事順序**：晶片發表會 → 晶片異常 → 變成殭屍 → 老黃打電話給三人（左右分割畫面，內容用字幕交代：裝甲車在營地深處、頂樓有火箭、快來）→ 三人緊張地抄起傢伙出發。
**基調**：發表會是刺眼的綠色舞台光；出事後轉成灰綠霧和近乎全黑。開場的三人還沒變兇悍：衣服乾淨、臉上沒有血，表情緊張。
**音樂**：發表會是科技感的電子音樂；`c1_04` 晶片故障時音樂卡住變成雜訊；之後是低沉的持續低音；`c1_13` 三人抄起傢伙時加入心跳般的鼓點；`c1_17` 收掉，只剩風聲。

**賽博龐克英文字幕（剪輯時加，不畫進圖裡）**
- 字型：等寬的科技感字體，例如 Google Fonts 的 Share Tech Mono 或 Orbitron；全大寫、句子短。
- 顏色：螢光綠 `#76ff3a`（遊戲第二章招牌的綠）為主，少量洋紅 `#ff2bd6` 點綴。
- 效果：逐字打出（打字機效果）；出現和消失時故障抖動、RGB 色彩分離；加一層淡淡的掃描線。
- 位置：分割畫面的通話字幕放在畫面下方正中間，跨過分隔線；其他放畫面下方。

### `c1_01`｜大遠景｜從會場最後面往舞台看｜緩推｜5 秒 — 老黃的晶片發表會
- **畫面**：一場盛大的科技產品發表會。前景是一排排觀眾的後腦和後頸，每個人後頸都嵌著一片小小的金屬晶片。遠處是巨大的舞台，舞台後方的大螢幕上是一片巨大晶片的圖樣（沒有字）。老黃站在舞台中央，被大螢幕的光打成一個小小的黑色剪影，雙手張開。
- **光線**：大螢幕的綠光是唯一的光源，觀眾席是暗的。
- **動作**：鏡頭慢慢往舞台推近，觀眾舉手鼓掌。
- **聲音**：滿場歡呼、科技感的電子音樂。
- **字幕（建議）**：`MVIDIA NEURO-CHIP // THE FUTURE IS INSIDE YOU`

### `c1_02`｜中景｜平視｜固定｜3 秒 — 他發表的就是這片晶片
- **畫面**：老黃站在舞台上面向觀眾，自信地微笑，右手拇指和食指捏著一片指甲大小的金屬晶片，舉在臉旁邊。背景是大螢幕的綠光。
- **光線**：大螢幕的綠光從背後勾出他的輪廓，晶片本身發出綠光，照亮他的眼鏡和臉。
- **動作**：他把晶片舉高，晶片的綠光一閃一閃。
- **聲音**：歡呼聲變小，晶片啟動的嗡鳴。
- **注意**：目前採用的 v01 只拍到手，可以用；想讓老黃在發表會露臉再照這格重畫。

### `c1_05`｜特寫｜背面｜固定｜3 秒 — 每個人的晶片都失控了

- **動作**：抽搐的人撲向旁人，人群往鏡頭湧來。

### `c1_08`｜大遠景｜平視｜緩推｜5 秒 — 整座城市淪陷
- **畫面**：深夜。前景左右各一台燒黑的廢車，裂開的柏油路上有積水倒映天空。中景兩排空殼大樓夾出一條大街。背景正中央是總部大樓，比周圍都高，樓頂一圈綠色發光面板（沒有字）。三四道黑煙從城市各處升起。

- **動作**：鏡頭沿大街緩緩推向大樓；黑煙往右飄，兩三隻烏鴉從左飛到右，樓頂綠光微微閃。

### `c1_10`｜大遠景｜俯角｜緩推｜4 秒 — 三人在山上的營地

### `c2_01`｜遠景｜平視｜緩推｜4 秒 — 找到車了（接第一章結尾）

### `c4_08`｜全景｜平視｜固定｜3 秒 — 老黃被抓

## 過場 5：結局（8 鏡，約 32 秒）

**基調**：打贏後頂樓的煙塵、火箭點火的白光、太空的黑；火星是暗鏽紅，這段的紅色可以破例多用一點，代表新的世界。
**音樂**：倒地之後一片安靜；按指紋後音樂漸強，到升空最高點；太空段落轉成平靜的鋼琴或弦樂；最後收在風聲。

### `c5_01`｜全景｜低角度｜固定｜4 秒 — 打贏了
- **畫面**：鏡頭貼著頂樓地面，巨型殭屍往前倒下，砸在畫面中間、壓碎欄杆，背上的晶片一片片熄滅。前景是 A 的靴子和滴血的球棒，B 和 C 在兩側喘氣。
- **光線**：晶片熄滅後畫面變暗，只剩火箭的綠燈。
- **動作**：轟然倒地，塵土和碎石揚起。
- **聲音**：巨大的倒地聲，接著一片安靜。
- **接下一鏡**：塵土落下後切。

### `c5_02`｜中景｜背面｜固定｜4 秒 — 老黃還活著
- **畫面**：巨型殭屍腫脹的肚子破開，老黃背對鏡頭趴在一灘黏液裡，全身黏液，黑色外套濕透。三人站在後面看。
- **光線**：火箭的綠光照在黏液上反光。
- **動作**：他慢慢舉起一隻手，比了個讚。
- **聲音**：黏液滑落聲、咳嗽聲，C 噗嗤笑出來（只有笑聲）。
- **接下一鏡**：比讚之後切。

### `c5_03`｜特寫｜平視｜固定｜3 秒 — 火箭啟動
- **畫面**：掃描台，一隻沾滿黏液的手掌按在上面，A 的手扶著他的手腕。八格燈亮了三格。
- **光線**：掃描台的綠光從下往上照。
- **動作**：剩下的燈一格一格亮起，全亮後閃一下。
- **聲音**：嗶聲一格一格響，最後一聲長音，火箭內部開始運轉。
- **接下一鏡**：用長音接點火聲。
- **注意**：開場已經沒有交代「火箭要老黃的指紋」，要不要在 `c3_04` 老黃來電時補一句字幕，待決定。

### `c5_04`｜大遠景｜仰角｜由下往上搖｜5 秒 — 離開地球
- **畫面**：從城市街道往上看，總部大樓頂端的火箭點火升空，噴出一道白色火柱；下方街道擠滿抬頭往上看的殭屍輪廓。
- **光線**：火箭的白光照亮整棟大樓和雲層，殭屍成了剪影。
- **動作**：火箭往上衝，鏡頭跟著往上搖。
- **聲音**：點火轟鳴，音樂到最高點。
- **接下一鏡**：白光溶接到艙內。

### `c5_05`｜中景｜平視｜微震｜3 秒 — 四人都在
- **畫面**：狹窄的火箭艙內，四個座位兩兩相對。A、B、C 繫著安全帶，老黃坐在最靠鏡頭的位置，身上還有黏液。C 嫌棄地往旁邊挪。
- **光線**：艙內儀表板的綠光，小窗外的白光。
- **動作**：艙內劇烈震動，接著慢慢平穩；B 閉上眼睛。
- **聲音**：震動的轟鳴越來越小。
- **接下一鏡**：從小窗推出去。

### `c5_06`｜主觀｜窗外｜緩拉｜4 秒 — 告別地球
- **畫面**：從火箭的圓形小窗往外看，地球在黑色的太空裡越來越小。夜晚那一半原本的城市燈光幾乎都熄了，只剩零星的綠點。
- **光線**：太空全黑，地球邊緣一圈淡淡的光。
- **動作**：地球慢慢遠去縮小。
- **聲音**：轟鳴完全消失，轉成平靜的音樂。
- **接下一鏡**：溶接到火星。

### `c5_07`｜大遠景｜平視｜固定｜4 秒 — 抵達火星
- **畫面**：火星表面，暗鏽紅色的沙丘和岩石，遠處有幾座圓頂建築和天線組成的基地。火箭噴著火往下降落，揚起紅色沙塵。
- **光線**：低垂的冷白太陽、紅色沙塵。
- **動作**：火箭降落，沙塵往外擴散。
- **聲音**：降落的推進聲、沙塵聲。
- **接下一鏡**：沙塵落下後切。

### `c5_08`｜大遠景｜背面｜緩拉｜5 秒 — 重新開始
- **畫面**：基地前的小丘上，四人背影站成一排看向紅色地平線：A 把球棒扛在肩上，B 的步槍背在背後，C 雙手插在口袋，老黃站在中間，身上還有乾掉的黏液。身後是降落好的火箭和基地圓頂。
- **光線**：地平線上的太陽把四人的影子拉得很長。
- **動作**：鏡頭慢慢往後拉高，四人越來越小。
- **聲音**：風聲，音樂收尾。
- **字幕**：完
- **接下一鏡**：淡出。
