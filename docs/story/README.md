# 故事總覽

三位主角要闖進 MVIDIA 公司總部，救出被困在裡面的老黃，最後搭火箭離開。遊戲是三人合作的第一人稱殭屍射擊，故事分成三章。

> 本作是課程專題的虛構故事，人物與公司名稱皆為虛構。

## 角色

| 角色 | 設定 |
|---|---|
| 情婦 A、情婦 B、情婦 C | 三位主角，各由一位玩家操作 |
| 老黃 | MVIDIA 公司的老闆，被困在公司總部，是要解救的人質 |
| Elon Mask | 提供逃生用的火箭 |
| 最終 Boss | 在總部頂樓出現並抓走老黃，打倒牠才能離開 |

## 三章一覽

| 章 | 名稱 | 目標 |
|---|---|---|
| 第一章 | [找車](chapter-1.md) | 穿過起霧的山路，找到可以離開的車 |
| 第二章 | [堅守陣地](chapter-2.md) | 守住陣地，擋下一波一波的殭屍 |
| 第三章 | [總部救人](chapter-3.md) | 在公司總部收集火箭燃料、救出老黃、打倒最終 Boss |

第三章最後的頂樓決戰另外寫在[最終 Boss 與結局](final-boss.md)。
