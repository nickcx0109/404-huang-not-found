# 第三章：總部救人

三位主角進入 MVIDIA 公司總部，要先收集火箭燃料，再搭電梯到頂樓找老黃。

## 流程

1. 在公司裡找火箭的燃料桶。
2. 收集到足夠的數量後，搭電梯到頂樓。
3. 在頂樓見到老黃，並迎戰最終 Boss，詳見[最終 Boss 與結局](final-boss.md)。

## 燃料桶規則

| 項目 | 規則 |
|---|---|
| 總數 | 公司裡散落約 20 桶 |
| 需要的數量 | 找到 10 桶就夠 |
| 搬運方式 | 背在身上 |
| 背著時 | 移動速度變慢 |
| 被打到 | 燃料桶會爆炸，背的人受傷 |
| 爆炸之後 | 那一桶作廢，要重新去找別桶 |

## 過關條件

收集滿 10 桶燃料，並搭電梯抵達頂樓。
