# 第三章：總部救人

三位主角進入 MVIDIA 公司總部，老黃來電說頂樓的火箭沒有燃油。三人要收集燃料桶送進貨梯，貨梯會把燃料送上頂樓，但載重不夠載人。通往頂樓的樓梯又被殭屍破壞堵死，所以三人還要到某間辦公室拿權限卡，才能搭電梯上頂樓。

## 流程

1. 在公司裡找火箭的燃料桶，背到貨梯放進去。
2. 送滿需要的數量後，到辦公室拿權限卡。
3. 用權限卡搭電梯到頂樓。
4. 在頂樓見到老黃，並迎戰最終 Boss，詳見[最終 Boss 與結局](final-boss.md)。

## 燃料桶規則

| 項目 | 規則 |
|---|---|
| 總數 | 公司裡散落約 20 桶 |
| 需要的數量 | 找到 10 桶就夠 |
| 搬運方式 | 背在身上 |
| 背著時 | 移動速度變慢 |
| 被打到 | 燃料桶會爆炸，背的人受傷 |
| 爆炸之後 | 那一桶作廢，要重新去找別桶 |

## 過關條件

把 10 桶燃料送進貨梯、拿到權限卡，並搭電梯抵達頂樓。
