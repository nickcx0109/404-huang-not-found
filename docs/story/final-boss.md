# 最終 Boss 與結局

第三章的最後一段發生在公司總部的頂樓，打倒最終 Boss 才能帶著老黃搭火箭離開。火箭要老黃的指紋才能發射，所以一定要把他救回來。

## 流程

1. 三位主角搭電梯抵達頂樓，與老黃會合。
2. 老黃正要按指紋啟動火箭時，突變的巨型殭屍從頂樓邊緣爬上來，一把抓起老黃吞下肚。
3. 三人合力和巨型殭屍戰鬥。
4. 打贏之後，老黃從牠的肚子裡滑出來，全身黏液但還活著。
5. 老黃按下指紋，四人搭上 Elon Mask 提供的火箭，前往他祕密發展的火星基地。

## 過關條件

打倒最終 Boss。沒有打贏就不能離開。
